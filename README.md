# EarnEase

EarnEase is a student-focused micro-work platform that connects university students with clients who need small online tasks completed.


## Project Idea

The main goal of EarnEase is to help students earn flexibly without sacrificing their education.

Unlike a general freelancing platform, EarnEase considers both:
- Student skills
- Student weekly available hours

This allows tasks to be recommended based on what a student can actually manage alongside their studies.

## Main Features

### Student
- 3-step student registration
- Skills selection
- Weekly free-hour setting
- Currency and monthly earning goal
- Dashboard
- Find Work
- Skill matching
- Weekly time matching
- Save and drop tasks
- Start task and mark completed
- Earnings tracking
- Profile editing
- Dark and light mode

### Client
- Client registration
- Profession selection
- Post work
- Choose category, estimated time, budget and currency
- View posted work
- Close and reopen posts

### Task Matching

Tasks are matched using:
- Required skills
- Weekly available hours
- Estimated task duration

A task can be shown as:
- Fits my week
- Tight
- Split across days
- Needs more free time

### Task Locking

Once a student starts a task, other students cannot start or complete the same task.

The task is marked as in progress and is removed from recommendations for other students.

## Data Storage

This is a frontend-only prototype.

All application data is stored locally in the browser using localStorage.

No backend or real database is used.

Passwords are not stored.

## Important Prototype Notice

All tasks, budgets and time estimates are illustrative examples only.

They are not real job offers and do not guarantee earnings.

No real payments are processed through this prototype.
