# 🌿 EarnEase

**EarnEase** is a web-based dashboard project designed to provide a clean and user-friendly interface for managing team information, match results, standings, and related activities.

🔗 **Live Website:**  https://sayedapriti.github.io/EarnEase/

📂 **GitHub Repository:** https://github.com/sayedapriti/EarnEase.git

## ✨ Features

- 📊 Interactive dashboard
- 🌙 Dark and light theme support
- 📱 Responsive layout for different screen sizes
- 👥 Team information and management interface
- 🏆 Match results and standings tables
- 📝 Forms for entering information
- 🔔 Notification messages
- 🪟 Modal dialogs
- 🎨 Modern green-themed user interface

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **Tailwind CSS** — Utility-first styling
- **CSS3** — Custom styling and special visual effects
- **JavaScript** — Interactive features and dynamic behavior
